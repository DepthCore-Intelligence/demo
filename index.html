深度的下游任务

三个下游任务均由同一个 Depth RSI Agent 驱动，分别在 RoboDojo Precision、OmniNavBench 与 GRScenes-SI 中接入四种深度输入，观察深度感知如何影响机器人的判断与行动。

操作

RoboDojo Precision。Depth RSI Agent 接收不同深度输入，完成空间定位与精细操作。

导航

OmniNavBench。Depth RSI Agent 在复杂室内环境中理解自然语言指令，完成转向、行进、回撤与目标靠近。

空间推理

GRScenes-SI。Depth RSI Agent 查看场景画面并调用深度工具，回答关于物体距离与相对方向的问题，还原三维空间关系。
